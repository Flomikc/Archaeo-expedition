# Тесты

Тестирование будет добавлено на этапе стабилизации MVP.

## Планируемые тесты

- `LevelGenerator` — проверка достижимости всех комнат (BFS).
- `SaveSystem` — сохранение и загрузка прогресса.
- `ShopSystem` — списание монет, проверка лимитов.
- `ArtifactSystem` — слияние 3 одинаковых, расчёт цены.

## Стек

- **Vitest** — юнит-тесты.
- **Playwright** — UI-тесты (для фазы 2).
