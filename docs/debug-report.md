## Найденные ошибки

### Ошибка 1: Артефакт не найден по ID
- **Тип:** логическая
- **Где:** `src/systems/ArtifactSystem.ts`, метод `getPrice`
- **Симптом:** при передаче несуществующего индекса возвращался `NaN`
- **Причина:** метод обращался к `data.artifacts[index]` без проверки границ
- **Решение:** добавить проверку `if (index < 0 || index >= data.artifacts.length) return 0;`
- **Статус:** исправлено
- **Коммит:** [хеш]

### Ошибка 2: localStorage переполнен
- **Тип:** времени выполнения (системная)
- **Где:** `src/systems/SaveSystem.ts`, метод `save`
- **Симптом:** при забитом хранилище игра падала без сообщения
- **Причина:** `localStorage.setItem` выбрасывал `QuotaExceededError`, который не ловился
- **Решение:** обернуть в `try/catch`, логировать в консоль, игра продолжает работать
- **Статус:** исправлено
- **Коммит:** [хеш]

### Ошибка 3: Слияние артефактов с недостатком предметов
- **Тип:** бизнес-логика
- **Где:** `src/systems/ArtifactSystem.ts`, метод `mergeFirstOfKind`
- **Симптом:** слияние запускалось, даже если у игрока меньше 3 артефактов
- **Причина:** отсутствовала проверка длины массива
- **Решение:** добавить проверку `if (indices.length < 3)` с возвратом понятной ошибки
- **Статус:** исправлено
- **Коммит:** [хеш]

### Ошибка 4: Покупка при недостатке монет
- **Тип:** бизнес-логика
- **Где:** `src/systems/ShopSystem.ts`, метод `buy`
- **Симптом:** предмет списывался, даже если у игрока не хватало монет
- **Причина:** проверка `canBuy` вызывалась, но результат не учитывался во всех ветках
- **Решение:** централизовать проверку, вернуть понятное сообщение пользователю через тост
- **Статус:** исправлено
- **Коммит:** [хеш]

### Ошибка 5: Дублирование raycast в InteractionSystem
- **Тип:** интеграции
- **Где:** `src/systems/InteractionSystem.ts` + `src/scenes/ExpeditionScene.ts`
- **Симптом:** в отдельных сценах повторялась одна и та же логика raycast
- **Причина:** копипаст при разработке
- **Решение:** вынести общий метод, использовать везде через `InteractionSystem`
- **Статус:** запланировано на рефакторинг
- **Коммит:** —
