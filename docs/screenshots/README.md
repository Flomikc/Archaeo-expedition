## Как снять

1. Открыть игру в браузере.
2. F12 → DevTools.
3. Воспроизвести ситуацию.
4. Win: `Win + Shift + S`, Mac: `Cmd + Shift + 4`.
5. Сохранить в эту папку с указанным именем.
