## Выбранная стратегия: GitHub Flow (расширенный)

### Обоснование

Проект разрабатывается одним человеком в учебных целях. Git Flow с отдельной веткой `develop` избыточен. GitHub Flow достаточен:

- `main` — всегда стабильная версия, готовая к показу.
- `feature/*` — новые функции.
- `bugfix/*` — исправления конкретных багов.
- `release/*` — подготовка релиза.

### Правила

1. **`main` всегда рабочая.** Тесты зелёные, игра запускается.
2. **Новая функция — отдельная ветка.** Даже мелкая.
3. **Коммиты осмысленные.** Формат: `<тип>: <описание>` (`feat:`, `fix:`, `docs:`, `test:`).
4. **Слияние — через merge** (в проекте с одним разработчиком PR-ревью необязательно).
5. **Релиз — через тег** `vX.Y.Z` на `main`.
6. **Хотфиксы — прямо в `main`** при критических багах.

### Использованные ветки

| Ветка | Назначение | Статус |
|-------|-----------|--------|
| `main` | Основная | Активна |
| `feature/expedition-timer-update` | Таймер 480 сек | Слита |
| `feature/expedition-timer-tuning` | Таймер 360 сек | Слита (конфликт разрешён) |
| `release/v1.0` | Подготовка релиза v1.0 | Слита в `main` |
| `bugfix/tab-flicker` | Исправление BR-04 (мерцание UI) | Слита в `main` |

### Разрешённые конфликты

**Конфликт 1: `ExpeditionScene.ts`, константа `MISSION_TIME`**

- **Ветки:** `feature/expedition-timer-update` (480 сек) vs `feature/expedition-timer-tuning` (360 сек).
- **Причина:** обе ветки меняли одну строку.
- **Решение:** выбран компромисс — 420 сек с комментарием в коде.
- **Коммит:** см. `git log --grep="конфликт"`.

**Конфликт 2: `package.json`, блок `scripts`**

- **Ветки:** `release/v1.0` vs `main`.
- **Причина:** в обеих версиях добавлены разные скрипты.
- **Решение:** объединены оба набора.

### Реальные багфиксы (не через конфликт)

**BR-04: мерцание UI при переключении вкладок ноутбука**

- **Ветка:** `bugfix/tab-flicker`
- **Исправление:** изменён порядок операций в `HUD.setLaptopTab` — сначала показывается новая панель, потом скрываются старые.
- **Причина:** в старой версии между «скрыть все» и «показать нужную» был пустой кадр.
- **Коммит:** см. `git log --grep="BR-04"`.
