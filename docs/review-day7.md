## Комментарии

### Комментарий 1. Полнота списка исключений

**Что проверено:** `docs/exceptions.md`.

**Замечание:** 10 ситуаций — это хорошо. Покрыты бизнес-логика, валидация, система, сеть (потенциально), доступ.

**Предложение:** добавить ещё 2–3 ситуации, связанные с сетевыми запросами к SDK Яндекс Игр (когда будет интеграция). Например:
- Ошибка авторизации в SDK.
- Покупка не завершена (отмена пользователем).
- Облачное сохранение недоступно.

**Статус:** принято к сведению, добавим в фазе 2.

### Комментарий 2. Иерархия классов исключений

**Что проверено:** `src/systems/errors.ts`.

**Замечание:** структура `GameError → 5 подклассов` логична. Наличие поля `code` и `context` — правильный подход для отладки.

**Предложение:** добавить метод `toUserMessage(): string` в базовый класс, чтобы каждая ошибка могла выдать понятное сообщение пользователю без дублирования логики в сценах.

**Статус:** запланировано на рефакторинг.

### Комментарий 3. Логирование

**Что проверено:** все `catch`-блоки в системах.

**Замечание:** во всех catch используется `console.error` с префиксом `[Класс.метод]` — это хорошо для отладки.

**Предложение:** вынести логирование в отдельный `Logger` с уровнями (`debug`, `info`, `warn`, `error`), чтобы в продакшене отключать debug-логи.

**Статус:** запланировано на этап интеграции SDK.

### Комментарий 4. Обработка `localStorage`

**Что проверено:** `SaveSystem.save` и `SaveSystem.load`.

**Замечание:** корректно ловится `QuotaExceededError` через try/catch. При повреждённом JSON — fallback на `emptySave()`. Это правильно.

**Предложение:** добавить счётчик неудачных сохранений и после 3-х подряд показать пользователю тост «Прогресс не сохраняется, проверьте настройки браузера».

**Статус:** запланировано на фазу 2.

### Комментарий 5. Полнота отчёта об отладке

**Что проверено:** `docs/debug-report.md`, раздел «День 7».

**Замечание:** раздел заполнен, все 10 ситуаций отмечены как проверенные. Есть таблица с классами исключений.

**Предложение:** добавить в раздел скриншоты реальных ошибок в DevTools (4 штуки).

**Статус:** скриншоты добавлены.
