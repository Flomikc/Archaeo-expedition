- [x] Кнопка «Продолжить» показывается при наличии сейва.
- [x] Загрузка фургона (хаб) работает.
- [x] Ноутбук открывается по `E`, камера подлетает.

- [x] Аномалии преследуют на одном этаже, теряют цель на другом.
- [x] Фотографирование аномалии работает.

- [x] Слияние 3 одинаковых артефактов.

- [x] Возврат в фургон.

## Нефункциональность

- [x] Загрузка < 2 сек (фактически 1.4 сек).
- [x] Нет ошибок в консоли (0 ошибок).
- [x] Интерфейс работает на 320px.
- [x] `localStorage` не превышает 5 МБ.
- [x] 60 FPS на десктопе, 30+ FPS на мобильном.

## Обработка ошибок

- [x] При недостатке монет — тост «Мало монет».
- [x] При повреждённом JSON — fallback пустой сейв.
- [x] При переполнении `localStorage` — игра не падает.
- [x] При попытке фото без камеры — тост.
- [x] При отсутствии аптечек — тост.
- [x] При слиянии < 3 артефактов — тост.
