# Руководство пользователя
## Артефакт: Наследие (Archaeo-expedition)

**Версия:** 1.0
**Дата:** 06.10.2026
**Платформа:** Веб (браузер)

---

## 1. Введение

«Артефакт: Наследие» — браузерная 3D-игра от первого лица об археологических экспедициях. Игрок управляет археологом, который унаследовал дело исчезнувшего друга: ездит на фургоне-мастерской по древним локациям, находит проклятые артефакты, реставрирует их и продаёт, постепенно приближаясь к разгадке исчезновения.

**Для кого:**
- **Игрок** — основной пользователь, проходит игровой цикл.
- **Разработчик** — запускает проект локально, тестирует (см. `install-guide.md`).

Игра однопользовательская, регистрация не требуется. Прогресс сохраняется автоматически в браузере.

---

## 2. Начало работы

### 2.1. Открытие приложения

1. Откройте современный браузер: **Chrome**, **Firefox** или **Edge** (последние версии).
2. Перейдите по ссылке на игру (или запустите локально через `npm run dev`).
3. Дождитесь загрузки главного меню (обычно 1.4 сек).

### 2.2. Начало игры

- **Играть** — начать с чистого прогресса (стартовый капитал 50 монет).
- **Продолжить** — загрузить сохранение (появляется, если вы уже играли).

Регистрация не нужна. Прогресс сохраняется в `localStorage` браузера автоматически.

## 3. Основные функции

### 3.1. Управление в 3D

| Клавиша | Действие |
|---------|----------|
| **W / A / S / D** | Движение вперёд / влево / назад / вправо |
| **Мышь** | Обзор |
| **Shift** | Бег |
| **Space** | Прыжок |
| **E** | Взаимодействие (открыть, взять, использовать) |
| **F** или **ЛКМ** | Фотография (в экспедиции) |
| **H** | Использовать аптечку |
| **Колесо мыши** | Сузить/расширить пучок фонарика |
| **ESC** | Пауза / настройки |

### 3.2. Сцена-хаб (фургон)

Фургон — центральная точка между экспедициями. Внутри:

- **Ноутбук** (стол слева). Нажать `E` → камера подлетает к экрану, появляется интерфейс с 4 вкладками:
  - **Карта** — выбор локации («Египет» → выезд).
  - **Магазин** — покупка снаряжения.
  - **Артефакты** — продажа, реставрация, слияние.
  - **Записи** — лор (в разработке).
- **Верстак** (справа). Нажать `E` → мини-игра реставрации артефакта.
- **Фотоаппарат** (на столе). Нажать `E` → взять в руку.
- **Выход наружу** — у передней стенки фургона, `E`.

### 3.3. Магазин

Открывается через ноутбук → вкладка «Магазин». Товары:

| Товар | Цена | Эффект |
|-------|------|--------|
| Отмычка | 50 | Открытие дверей вручную (мини-игра) |
| Автовзлом | 100 | Мгновенное открытие (расходник) |
| Плёнка +5 | 75 | +5 снимков в экспедиции |
| Алмазное сверло | 200 | Бур работает на 25% быстрее (навсегда) |
| Аптечка | 80 | +50 HP, использовать по `H` |

**Совет:** на старте ровно 50 монет — хватает на отмычку. Без неё в пирамиду не попасть.

### 3.4. Выезд на локацию

1. Открыть ноутбук.
2. Вкладка «Карта» → выбрать **Египет**.
3. Камера вернётся, вы окажетесь в пустыне у фургона.
4. Идти пешком к пирамиде по каменной дорожке.

### 3.5. Взлом двери

У входа в пирамиду — каменный замок. При нажатии `E`:

1. Открывается круглый циферблат с 8 секторами.
2. **Зелёный сектор** — цель.
3. **Стрелка** движется по кругу.
4. Нажать **ЛКМ** или **Пробел**, когда стрелка в зелёной зоне.
5. Пройти **3 круга** подряд. Каждый круг стрелка быстрее.
6. **3 промаха** → дверь заклинило, есть кнопки «Попробовать снова» / «Вернуться к фуре».

### 3.6. Экспедиция (пирамида)

Внутри — процедурно-генерируемая пирамида:
- **3 этажа**, на каждом 4×4 комнаты.
- Комнаты: коридор, зал, ловушка, сокровищница, колонны, лестница, финал.
- Между этажами — лестницы.

**Цель:** найти финальную комнату с буром на верхнем этаже.

### 3.7. Бур и раскопки

В финальной комнате стоит бур. При нажатии `E`:
- Запускается таймер раскопок (7 минут).
- Прогресс-бар внизу экрана.
- Пока бур работает, спавнятся **аномалии** — духи-враги.

### 3.8. Аномалии и фотографирование

Аномалия — враждебный дух. Преследует игрока, если он на том же этаже, иначе патрулирует.

- **Атака:** −10 HP при касании (кулдаун 2 сек).
- **Защита:** навести прицел и нажать **ЛКМ** или **F**. Аномалия исчезает, счётчик снимков −1.
- Если плёнка кончилась — фотографировать нельзя.

### 3.9. Реставрация артефактов

После успешной экспедиции артефакты попадают в инвентарь «сырыми». Откройте ноутбук → вкладка «Артефакты» → кнопка **«Реставрировать»**.

Мини-игра: обвести контур артефакта мышью, не отрывая кнопку.
- **Точность ≥ 0.8** — качество высокое, цена выше.
- **Точность < 0.5** — качество низкое, но артефакт всё равно отреставрирован.
- **Отмена** — выйти без реставрации.

### 3.10. Слияние артефактов

3 одинаковых отреставрированных артефакта → 1 артефакт следующего уровня редкости.

**Редкости (5 уровней):**

| Редкость | Цвет | Источник |
|----------|------|----------|
| Обычный | Серый | Находки на локации (70%) |
| Необычный | Зелёный | Находки на локации (30%) |
| Редкий | Синий | Извлечено буром (70%) |
| Эпический | Фиолетовый | Извлечено буром (30%) |
| Легендарный | Золотой | Слияние 3 эпических |

При успехе создаётся **1 сырой** артефакт следующего уровня.

### 3.11. Продажа артефактов

Вкладка «Артефакты» → кнопка **«Продать»** напротив отреставрированного артефакта.

**Формула цены:** `baseValue × (0.5 + quality)`.
Пример: Скарабей (40) × качество 0.8 = 40 × 1.3 = **52 монеты**.

### 3.12. Завершение экспедиции

Когда бур завершён:
- Аномалии исчезают.
- Появляется **красный маркер** в стартовой комнате.
- Вернуться к маркеру, нажать `E` → экран «Вердикт миссии»:
  - Время экспедиции.
  - Осталось снимков.
  - Здоровье.
  - Найденные артефакты (2 шт.: 1 находка + 1 извлечено буром).
  - Награда (базовая 100 + бонусы за скорость и снимки).

**Провал:**
- HP ≤ 0 → «Вы потеряли сознание».
- Время истекло → «Время вышло».

## 5. Часто задаваемые вопросы

**В: Прогресс сохраняется автоматически?**
О: Да, в `localStorage` браузера. При закрытии вкладки и повторном заходе — прогресс восстановится.

**В: Что делать, если не хватает монет на отмычку?**
О: Стартовый капитал — 50 монет, ровно на отмычку. Если вы её уже купили, а монет нет — идите в экспедицию без снаряжения: артефакты всё равно найдутся, а после продажи появятся монеты на апгрейды.

**В: Бур работает слишком долго.**
О: Купите «Алмазное сверло» (200 монет) в магазине — бур ускорится на 25%. Эффект постоянный.

**В: Аномалии не исчезают после фото.**
О: Проверьте счётчик снимков в HUD. Если 0 — плёнка кончилась, купите «Плёнку +5» в магазине.

**В: Что делать, если застрял в пирамиде?**
О: Нажмите `ESC` → «Вернуться в фуру». Экспедиция прервётся, прогресс по миссии сохранится (артефакты не начислятся).

**В: Можно играть на телефоне?**
О: Частично — управление оптимизировано для десктопа. Полноценная мобильная поддержка запланирована в фазе 2.

**В: Где посмотреть лор?**
О: В ноутбуке вкладка «Записи». На текущей версии — заглушка, лор добавляется в фазе 2.
