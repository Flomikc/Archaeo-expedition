### Возникшие проблемы

**Проблема:** При клонировании приватного репозитория GitHub возникла ошибка 403 (Write access not granted) при использовании fine-grained токена.

**Причина:** Fine-grained токены требуют явного указания прав на конкретный репозиторий. Стандартная галочка `repo`, к которой я привык, есть только у classic-токенов.

**Решение:** Создан classic Personal Access Token с scope `repo`. Клонирование прошло успешно. Токен добавлен в remote URL, после клонирования заменён на чистый адрес во избежание утечки.

- `ValidationError` — ошибки валидации.
- `ShopError` — ошибки магазина.
- `ArtifactError` — ошибки артефактов.

Плюс утилиты: `safeJsonParse`, `isValidString`, `isValidPositiveNumber`.

**3. Реализована обработка**

- `ShopSystem.buy` обёрнут в try/catch, добавлена валидация `id`.
- `ArtifactSystem.getPrice` проверяет границы массива.
- `ArtifactSystem.mergeFirstOfKind` валидирует количество.
- `SaveSystem.save` ловит `QuotaExceededError`.
- Все ошибки логируются с префиксами `[Класс.метод]`.

**4. Стратегии обработки**

Применены три подхода:
- **Fail fast** — для ошибок конфигурации.
- **Graceful degradation** — при ошибке сохранения игра работает.
- **Fallback** — повреждённые данные → `emptySave()`.

**Решение:** классифицировал по приоритетам — критические / важные / желательные. Для каждого — своя стратегия.
