# Слайд 2. Проблема и актуальность

**Проблема**
- 3D-игры требуют установки клиента (Steam, App Store).
- Браузерные 3D-проекты в нише казуальных игр почти отсутствуют.

**Решение**
- Игра, работающая прямо в браузере, без установки.
- Занимает пустую нишу — cozy mystery в 3D.

---

# Слайд 3. Цель и задачи

**Цель**
Создать MVP браузерной 3D-игры, готовой к публикации на Яндекс Играх.

**Задачи**
1. Освоить Babylon.js + TypeScript + Vite.
2. Реализовать хаб, экспедицию, экономику.
3. Процедурная генерация уровней.
4. Покрыть тестами критическую логику.
5. Подготовить документацию и релиз v1.0.

# Слайд 5. Функциональность (MVP)

**Что умеет игра**
- Сцена-хаб: фургон с ноутбуком, верстаком, фотоаппаратом.
- Процедурная генерация пирамиды (3 этажа, 4×4 комнат).
- Взлом двери — мини-игра.
- Бур с таймером раскопок.
- Аномалии с AI.
- Реставрация артефактов.
- 5 редкостей + слияние.
- Магазин снаряжения.
- Сохранения в localStorage.
