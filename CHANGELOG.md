# Changelog

Все значимые изменения проекта документируются в этом файле.
Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.0.0/).

## [1.0.0] — 05.10.2026

### Добавлено
- Сцена-хаб (фургон) с ноутбуком, верстаком, фотоаппаратом.
- Процедурная генерация пирамиды (3 этажа, 4×4 комнат).
- Система взлома двери (круговая мини-игра).
- Бур с таймером раскопок и апгрейдом скорости.
- Аномалии с AI (Patrol → Chase → Attack) с проверкой этажа.
- Фотографирование аномалий.
- Реставрация артефактов (мини-игра обводки).
- Слияние артефактов (3 → 1 следующего уровня).
- Продажа артефактов (5 редкостей).
- Магазин снаряжения.
- Система сохранений на `localStorage` с миграциями.
- Обработка исключений (ValidationError, ShopError, ArtifactError).
- 28 unit-тестов (Vitest 2.1) + CI через GitHub Actions.
- Отчёт о метриках качества (18/20 в норме).

### Исправлено
- BR-01: увеличен таймаут тостов.
- BR-02: блокировка кнопки покупки.
- NullEngine-совместимость `LevelGenerator.createMaterials`.
- Конфликт таймера миссии — 420 сек.

### Изменено
- Рефакторинг `ExpeditionScene.update()`.
- Добавлен JSDoc к публичным методам.
- Настроен `coverage.exclude`.

### Технологии
- TypeScript 5.5, Babylon.js 7.54, Vite 4.5, Vitest 2.1.
- CI: GitHub Actions. Хранение: localStorage. Node.js 20 LTS.
